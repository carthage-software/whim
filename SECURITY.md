# Security Policy

Whim is a toy programming language. Do not use it in production or for work
that needs a security guarantee.

## Supported versions

Whim has no supported versions. No release has a promised security update,
response time, or maintenance term.

## Report a security issue

Send a private report to [azjezz@carthage.software](mailto:azjezz@carthage.software).
Use `Whim security` in the subject. Include:

- The Whim version or commit.
- The operating system and CPU type.
- A small way to reproduce the issue.
- The effect you observed.
- Any limits on sharing the report.

Do not put secrets or private data in the report. Do not open a public issue
before the report becomes public.

The project offers no bug bounty or response deadline. A report may receive no
reply or fix.
