# Contributing to Whim

Whim does not accept pull requests. I do not have time to review external
changes. You may fork Whim under its licenses, but please do not send a patch
back to this repository.

## Issues

You may open an issue for a bug or an idea. Before you do:

- Search the open and closed issues.
- Test the latest release or the current `main` branch.
- Reduce a bug to a small, complete program.
- Include the Whim version, operating system, and CPU type.
- Show what you expected and what happened.

An issue does not create a promise to reply or make a change. Whim is an
experimental project with no support plan or fixed priorities. An issue may
wait for months, receive no work, or close without a change.

Use the process in [SECURITY.md](SECURITY.md) for a security report.
